## 2. Installation de CoolTerm

Le programme CoolTerm est utilisé pour lire les données sur le port série.

Télécharger le programme CoolTerm :

- macOS :

  - [Intel/ARM](https://freeware.the-meiers.org/CoolTermMac.dmg)
- Win :

  - [Intel 64Bit](https://freeware.the-meiers.org/CoolTermWin64Bit.zip)
  - [Intel 32Bit](https://freeware.the-meiers.org/CoolTermWin32Bit.zip)
  - [ARM 64Bit](https://freeware.the-meiers.org/CoolTermWinARM64Bit.zip)
- Linux :

  - [Intel 64Bit](https://freeware.the-meiers.org/CoolTermLinux64Bit.zip)
  - [Intel 32Bit](https://freeware.the-meiers.org/CoolTermLinux32Bit.zip)

(1) Après le téléchargement, nous devons installer le fichier du programme CoolTerm. Ci‑dessous, le système Windows est pris comme exemple.

(2) Choisissez "win" pour télécharger le fichier ZIP de CoolTerm.

(3) Décompressez le fichier et ouvrez‑le. (également adapté aux systèmes Mac et Linux)

![](./media/Makecode_00ec3601.gif)

Les fonctions de chaque bouton de la barre d'outils sont listées ci‑dessous :

![](./media/Makecode_4056f116.png)

| Commande   | Description                                      |
| ---------- | ------------------------------------------------ |
| New        | Ouvre un nouveau terminal                        |
| Open       | Ouvre une connexion enregistrée                  |
| Save       | Enregistre la connexion actuelle sur le disque   |
| Connect    | Ouvre la connexion série                         |
| Disconnect | Ferme la connexion série                         |
| Clear Data | Efface les données reçues                        |
| Options    | Ouvre la boîte de dialogue des options de connexion |
| HEX        | Affiche les données du terminal en format hexadécimal |
| View       | Affiche la fenêtre d'aide                        |

Une fois l'installation terminée, nous utiliserons cet outil dans les leçons suivantes.
