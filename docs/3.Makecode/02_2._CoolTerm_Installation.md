## 2. CoolTerm-installatie

Het CoolTerm-programma wordt gebruikt om gegevens op de seriële poort te lezen.

Download het CoolTerm-programma:

- macOS:

  - [Intel/ARM](https://freeware.the-meiers.org/CoolTermMac.dmg)
- Win:

  - [Intel 64Bit](https://freeware.the-meiers.org/CoolTermWin64Bit.zip)
  - [Intel 32Bit](https://freeware.the-meiers.org/CoolTermWin32Bit.zip)
  - [ARM 64Bit](https://freeware.the-meiers.org/CoolTermWinARM64Bit.zip)
- Linux:

  - [Intel 64Bit](https://freeware.the-meiers.org/CoolTermLinux64Bit.zip)
  - [Intel 32Bit](https://freeware.the-meiers.org/CoolTermLinux32Bit.zip)

(1) Na het downloaden moeten we het CoolTerm-programmabestand installeren. Hieronder wordt het Windows-systeem als voorbeeld genomen.

(2) Kies "win" om het zip-bestand van CoolTerm te downloaden.

(3) Pak het bestand uit en open het. (ook geschikt voor Mac- en Linux-systemen)

![](./media/Makecode_00ec3601.gif)

De functies van elke knop op de werkbalk staan hieronder vermeld:

![](./media/Makecode_4056f116.png)

| Commando   | Beschrijving                                      |
| ---------- | ------------------------------------------------- |
| New        | Opent een nieuwe Terminal                         |
| Open       | Opent een opgeslagen Verbinding                   |
| Save       | Slaat de huidige Verbinding op de schijf op      |
| Connect    | Opent de Seriële Verbinding                       |
| Disconnect | Sluit de Seriële Verbinding                       |
| Clear Data | Wis de Ontvangen Gegevens                         |
| Options    | Opent het dialoogvenster Verbindingopties         |
| HEX        | Toont de terminalgegevens in hexadecimale notatie |
| View       | Toont het helpvenster                              |

Na voltooiing van de installatie zullen we deze tool in de volgende lessen gebruiken.
