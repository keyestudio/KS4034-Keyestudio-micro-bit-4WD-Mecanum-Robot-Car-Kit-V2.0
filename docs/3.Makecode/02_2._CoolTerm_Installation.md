## 2. Installazione di CoolTerm

Il programma CoolTerm viene utilizzato per leggere i dati sulla porta seriale.

Scarica il programma CoolTerm:

- macOS:

  - [Intel/ARM](https://freeware.the-meiers.org/CoolTermMac.dmg)
- Win:

  - [Intel 64Bit](https://freeware.the-meiers.org/CoolTermWin64Bit.zip)
  - [Intel 32Bit](https://freeware.the-meiers.org/CoolTermWin32Bit.zip)
  - [ARM 64Bit](https://freeware.the-meiers.org/CoolTermWinARM64Bit.zip)
- Linux:

  - [Intel 64Bit](https://freeware.the-meiers.org/CoolTermLinux64Bit.zip)
  - [Intel 32Bit](https://freeware.the-meiers.org/CoolTermLinux32Bit.zip)

(1) Dopo il download, dobbiamo installare il file del programma CoolTerm; di seguito viene preso come esempio il sistema Windows.

(2) Scegliere "win" per scaricare il file ZIP di CoolTerm.

(3) Decomprimere il file e aprirlo. (adatto anche per sistemi Mac e Linux)

![](./media/Makecode_00ec3601.gif)

Le funzioni di ciascun pulsante sulla barra degli strumenti sono elencate di seguito:

![](./media/Makecode_4056f116.png)

| Comando    | Descrizione                                      |
| ---------- | ------------------------------------------------ |
| New        | Apre un nuovo Terminal                           |
| Open       | Apre una Connessione salvata                     |
| Save       | Salva la Connessione corrente su disco           |
| Connect    | Apre la Connessione Seriale                      |
| Disconnect | Chiude la Connessione Seriale                    |
| Clear Data | Cancella i Dati Ricevuti                         |
| Options    | Apre la finestra delle Opzioni di Connessione    |
| HEX        | Mostra i dati del Terminal in formato esadecimale |
| View       | Mostra la finestra di Aiuto                      |

Al termine dell'installazione, utilizzeremo questo strumento nelle lezioni successive.
