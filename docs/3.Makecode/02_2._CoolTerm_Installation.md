## 2. CoolTerm のインストール

CoolTerm はシリアルポートのデータを読み取るために使用するプログラムです。

CoolTerm プログラムをダウンロード：

- macOS:

  - [Intel/ARM](https://freeware.the-meiers.org/CoolTermMac.dmg)
- Win:

  - [Intel 64Bit](https://freeware.the-meiers.org/CoolTermWin64Bit.zip)
  - [Intel 32Bit](https://freeware.the-meiers.org/CoolTermWin32Bit.zip)
  - [ARM 64Bit](https://freeware.the-meiers.org/CoolTermWinARM64Bit.zip)
- Linux:

  - [Intel 64Bit](https://freeware.the-meiers.org/CoolTermLinux64Bit.zip)
  - [Intel 32Bit](https://freeware.the-meiers.org/CoolTermLinux32Bit.zip)

(1) ダウンロード後、CoolTerm のプログラムファイルをインストールする必要があります。以下では Windows システムを例として示します。

(2) 「win」を選択して CoolTerm の ZIP ファイルをダウンロードします。

(3) ファイルを解凍して開きます。（Mac および Linux システムにも適しています）

![](./media/Makecode_00ec3601.gif)

ツールバー上の各ボタンの機能は以下のとおりです：

![](./media/Makecode_4056f116.png)

| コマンド     | 説明                                              |
| ------------ | ------------------------------------------------- |
| New          | 新しいターミナルを開きます                         |
| Open         | 保存された接続を開きます                           |
| Save         | 現在の接続をディスクに保存します                   |
| Connect      | シリアル接続を開きます                             |
| Disconnect   | シリアル接続を閉じます                             |
| Clear Data   | 受信データをクリアします                           |
| Options      | 接続オプションのダイアログを開きます               |
| HEX          | ターミナルのデータを16進形式で表示します           |
| View         | ヘルプウィンドウを表示します                       |

インストールが完了したら、以降のレッスンでこのツールを使用します。
