## 2. CoolTerm-Installation

Das CoolTerm-Programm wird verwendet, um Daten über die serielle Schnittstelle zu lesen.

CoolTerm-Programm herunterladen:

- macOS:

  - [Intel/ARM](https://freeware.the-meiers.org/CoolTermMac.dmg)
- Win:

  - [Intel 64Bit](https://freeware.the-meiers.org/CoolTermWin64Bit.zip)
  - [Intel 32Bit](https://freeware.the-meiers.org/CoolTermWin32Bit.zip)
  - [ARM 64Bit](https://freeware.the-meiers.org/CoolTermWinARM64Bit.zip)
- Linux:

  - [Intel 64Bit](https://freeware.the-meiers.org/CoolTermLinux64Bit.zip)
  - [Intel 32Bit](https://freeware.the-meiers.org/CoolTermLinux32Bit.zip)

(1) Nach dem Download müssen wir die CoolTerm-Programmdatei installieren. Nachfolgend wird das Windows-System als Beispiel gezeigt.

(2) Wählen Sie "win", um die ZIP-Datei von CoolTerm herunterzuladen.

(3) Entpacken Sie die Datei und öffnen Sie sie. (Auch geeignet für Mac- und Linux-Systeme)

![](./media/Makecode_00ec3601.gif)

Die Funktionen der einzelnen Schaltflächen in der Symbolleiste sind unten aufgeführt:

![](./media/Makecode_4056f116.png)

| Befehl     | Beschreibung                                     |
| ---------- | ------------------------------------------------ |
| New        | Öffnet ein neues Terminal                        |
| Open       | Öffnet eine gespeicherte Verbindung              |
| Save       | Speichert die aktuelle Verbindung auf der Festplatte |
| Connect    | Öffnet die serielle Verbindung                   |
| Disconnect | Schließt die serielle Verbindung                 |
| Clear Data | Löscht die empfangenen Daten                     |
| Options    | Öffnet den Dialog für Verbindungsoptionen        |
| HEX        | Zeigt die Terminaldaten im hexadezimalen Format an |
| View       | Zeigt das Hilfefenster an                        |
