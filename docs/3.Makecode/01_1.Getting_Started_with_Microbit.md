## 1.Aan de slag met Micro:bit

Stap 1: verbind het Micro: Bit main board V2 met uw computer

Verbind eerst het Micro: Bit main board V2 met uw computer via de USB-kabel.

![](./media/Makecode_a21e48b4.png)

Stap 2: als de rode LED aan de achterkant van de plaat brandt, betekent dit dat de plaat van stroom wordt voorzien. Vervolgens verschijnt het Micro: Bit main board V2 op uw computer als een station met de naam 'MICROBIT'. Let op: dit is geen gewoon USB-station zoals hieronder weergegeven.

![](./media/Makecode_cbfceb10.png)

Stap 3: schrijf programma's

https://makecode.microbit.org/

![](./media/Makecode_fcdafc4a.gif)

Gefeliciteerd met het voltooien van je eerste code! Je zou nu de 5x5 LED dot matrix moeten zien die verschillende patronen weergeeft.

Vervolgens zal ik demonstreren hoe je de geschreven code naar de computer downloadt en deze op een andere manier uploadt.

![](./media/Makecode_cb45d185.gif)
