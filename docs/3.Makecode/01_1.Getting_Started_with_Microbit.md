## 1.Primi passi con Micro:bit

Passo 1: collega il Micro: Bit main board V2 al tuo computer

Per prima cosa, collega il Micro: Bit main board V2 al computer tramite il cavo USB.

![](./media/Makecode_a21e48b4.png)

Passo 2: se il LED rosso sul retro della scheda è acceso, significa che la scheda è alimentata. A questo punto il Micro: Bit main board V2 apparirà sul tuo computer come un'unità chiamata 'MICROBIT'. Si prega di notare che non si tratta di un normale disco USB come mostrato di seguito.

![](./media/Makecode_cbfceb10.png)

Passo 3: scrivere programmi

https://makecode.microbit.org/

![](./media/Makecode_fcdafc4a.gif)

Congratulazioni per aver completato il tuo primo codice! Ora dovresti vedere la 5x5 LED dot matrix che mostra vari schemi.

Successivamente mostrerò come scaricare il codice scritto sul computer e caricarlo utilizzando un metodo diverso.
