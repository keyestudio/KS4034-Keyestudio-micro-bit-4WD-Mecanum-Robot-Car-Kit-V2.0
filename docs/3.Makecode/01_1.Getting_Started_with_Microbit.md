## 1.Micro:bit のはじめ方

ステップ 1: Micro: Bit main board V2 をコンピュータに接続する

まず、Micro: Bit main board V2 を USB ケーブルでコンピュータに接続します。

![](./media/Makecode_a21e48b4.png)

ステップ 2: ボードの背面にある赤い LED が点灯している場合、ボードに電源が供給されています。その後、Micro: Bit main board V2 はコンピュータ上に 'MICROBIT' という名前のドライブとして表示されます。下図のように、これは通常の USB ドライブではないことに注意してください。

![](./media/Makecode_cbfceb10.png)

ステップ 3: プログラムを書く

https://makecode.microbit.org/

![](./media/Makecode_fcdafc4a.gif)

最初のコードを完成させたことをおめでとうございます！これで、さまざまなパターンを表示する 5x5 LED dot matrix が表示されるはずです。

次に、作成したコードをコンピュータにダウンロードし、別の方法でアップロードする手順を説明します。

![](./media/Makecode_cb45d185.gif)
