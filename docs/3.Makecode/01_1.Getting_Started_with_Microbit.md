## 1.Erste Schritte mit Micro:bit

Schritt 1: Verbinden Sie das Micro: Bit main board V2 mit Ihrem Computer

Schließen Sie zunächst das Micro: Bit main board V2 mit dem USB-Kabel an Ihren Computer an.

![](./media/Makecode_a21e48b4.png)

Schritt 2: Wenn die rote LED auf der Rückseite der Platine leuchtet, bedeutet das, dass die Platine mit Strom versorgt wird. Dann wird das Micro: Bit main board V2 auf Ihrem Computer als Laufwerk mit dem Namen 'MICROBIT' angezeigt. Bitte beachten Sie, dass es sich nicht um ein gewöhnliches USB-Laufwerk handelt, wie unten gezeigt.

![](./media/Makecode_cbfceb10.png)
