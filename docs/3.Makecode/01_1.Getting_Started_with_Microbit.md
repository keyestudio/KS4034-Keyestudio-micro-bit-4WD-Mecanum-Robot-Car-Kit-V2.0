## 1.Empezando con Micro:bit

Paso 1: conecta el Micro: Bit main board V2 a tu ordenador

En primer lugar, conecta el Micro: Bit main board V2 a tu ordenador mediante el cable USB.

![](./media/Makecode_a21e48b4.png)

Paso 2: si el LED rojo en la parte posterior de la placa está encendido, eso significa que la placa está alimentada. Entonces el Micro: Bit main board V2 aparecerá en tu ordenador como una unidad llamada 'MICROBIT'. Ten en cuenta que no es un disco USB ordinario como se muestra a continuación.

![](./media/Makecode_cbfceb10.png)

Paso 3: escribir programas

https://makecode.microbit.org/

![](./media/Makecode_fcdafc4a.gif)

¡Felicidades por completar tu primer código! Ahora deberías ver la 5x5 LED dot matrix mostrando varios patrones.

A continuación, demostraré cómo descargar el código escrito al ordenador y subirlo utilizando un método diferente.
