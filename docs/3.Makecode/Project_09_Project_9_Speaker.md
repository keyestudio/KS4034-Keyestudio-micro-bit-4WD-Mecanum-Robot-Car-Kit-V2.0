### (1)Proyecto Description:

La placa principal Micro: Bit main board V2 tiene un altavoz integrado, lo que facilita añadir sonido a los programas. Podemos programar el altavoz para emitir todo tipo de tonos, por ejemplo reproducir la canción *Ode to Joy*.

### (2)Components Needed:

Micro:bit main board V2 

Cable Micro USB

### (3)Test Code :

### (4)Test Results:
