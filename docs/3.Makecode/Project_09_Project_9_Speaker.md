### (1)Project Description:

De Micro: Bit main board V2 heeft een ingebouwde luidspreker, waardoor het toevoegen van geluid aan programma's eenvoudiger wordt. We kunnen de luidspreker programmeren om allerlei tonen af te spelen, bijvoorbeeld het lied *Ode to Joy*.

### (2)Components Needed:

Micro:bit main board V2 

Micro USB-kabel
