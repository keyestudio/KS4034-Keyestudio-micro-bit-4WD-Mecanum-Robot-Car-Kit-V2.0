### (1)Project Description:

Das Micro: Bit main board V2 verfügt über einen eingebauten Lautsprecher, wodurch das Hinzufügen von Tönen zu Programmen einfacher wird. Wir können den Lautsprecher so programmieren, dass er alle Arten von Tönen wiedergibt, etwa das Lied *Ode to Joy*.

### (2)Components Needed:

Micro:bit main board V2 

Micro USB-Kabel

### (3)Test Code :
