## Project 2: Light A Single LED

![](./media/Makecode_2423afc6.jpg)

[Klik hier om de code voor deze les te downloaden](./Code/Light-A-Single-LED.hex)

### (1)Projectbeschrijving:

(1)Projectbeschrijving: De LED-dotsmatrix bestaat uit 25 LEDs gerangschikt in een 5 × 5 vierkant. Om deze LEDs snel te kunnen lokaliseren, kunnen we deze matrix zoals in de onderstaande afbeelding als een coördinatensysteem beschouwen en twee assen maken door de rijen van 0 tot 4 van boven naar beneden en de kolommen van 0 tot 4 van links naar rechts te nummeren. De LED op de tweede positie van de eerste rij is dus (1,0) en de LED op de vijfde positie van de vierde kolom is (3,4), en zo verder.

![](./media/Makecode_4ab9ecab.png)

### (2)Benodigde componenten:

Micro:bit main board V2

Micro USB-kabel

### (3)Testcode:

Sluit het Micro:bit main board V2 met de Micro USB-kabel aan op uw computer en begin met bewerken.

### (4)Testresultaten

Na het uploaden van de code ziet u dat de Microbit-board het volgende effect weergeeft: (1,0) licht 0,5 seconden op en gaat dan uit, gevolgd door (3,4) dat 0,5 seconden oplicht en vervolgens uitgaat. Dit herhaalt zich in een lus.
