## 3.Makecode Extension Libraries

We hebben een Makecode-extensiebibliotheek gemaakt voor deze Mecanum-robotauto V2.0.

Voeg een extensiebibliotheek toe voor de Mecanum-robotauto V2.0.

Volg de volgende stappen om de extensiebestanden toe te voegen:

Open Makecode en open een project → klik op het tandwielpictogram (voor instellingen) rechtsboven → kies “**Extensions**”;

![makecode20](./media/Makecode_139fb536.png)

Of klik op “**Extensions**”, zoals hieronder weergegeven:

![makecode21](./media/Makecode_905cacbd.png)

Voer de link in:

```
https://github.com/keyestudio2019/mecanum_robot_v2
```

Klik op het zoekresultaat “**MecanumRobotV2**” om het te downloaden en te installeren. Dit proces kan een paar seconden duren.

![makecode22](./media/Makecode_605b9b18.png)

Na de installatie kunt u de extensiebestanden **Mecanum RobotV2** en **IrRemote** aan de linkerkant vinden.

En het extensiebestand Neopixel is ook geïnstalleerd.

![makecode23](./media/Makecode_0c07886b.png)
