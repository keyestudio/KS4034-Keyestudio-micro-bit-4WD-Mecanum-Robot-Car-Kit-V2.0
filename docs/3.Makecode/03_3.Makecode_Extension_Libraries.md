## 3.Makecode Extension Libraries

Abbiamo realizzato una libreria di estensione Makecode per questa auto robot Mecanum V2.0.

Aggiungere una libreria di estensione per l'auto robot Mecanum V2.0.

Segui i passaggi seguenti per aggiungere i file di estensione:

Apri Makecode e apri un progetto → fai clic sull'icona a forma di ingranaggio (per le impostazioni) nell'angolo in alto a destra → scegli “**Extensions**”;

![makecode20](./media/Makecode_139fb536.png)

Oppure fai clic su “**Extensions**”, come mostrato di seguito:

![makecode21](./media/Makecode_905cacbd.png)

Inserisci il link:

```
https://github.com/keyestudio2019/mecanum_robot_v2
```

Tocca il risultato della ricerca “**MecanumRobotV2**” per scaricarlo e installarlo. Questo processo potrebbe richiedere alcuni secondi.

![makecode22](./media/Makecode_605b9b18.png)

Dopo l'installazione, puoi trovare i file di estensione **Mecanum RobotV2** e **IrRemote** sul lato sinistro.

Anche il file di estensione Neopixel è installato.

![makecode23](./media/Makecode_0c07886b.png)
