## 3.Makecode Extension Libraries

このMecanumロボットカー V2.0用のMakecode拡張ライブラリを作成しました。

Mecanumロボットカー V2.0の拡張ライブラリを追加します。

拡張ファイルを追加するには、以下の手順に従ってください：

Makecodeを開いてプロジェクトを開く → 右上の歯車アイコン（設定）をクリック → “**Extensions**” を選択；

![makecode20](./media/Makecode_139fb536.png)

または、以下のように “**Extensions**” をクリック：

![makecode21](./media/Makecode_905cacbd.png)

以下のリンクを入力：

```
https://github.com/keyestudio2019/mecanum_robot_v2
```

検索結果の “**MecanumRobotV2**” をタップしてダウンロード・インストールします。処理には数秒かかる場合があります。

![makecode22](./media/Makecode_605b9b18.png)

インストール後、左側に拡張ファイル **Mecanum RobotV2** と **IrRemote** が表示されます。

拡張ファイル Neopixel もインストールされています。

![makecode23](./media/Makecode_0c07886b.png)
