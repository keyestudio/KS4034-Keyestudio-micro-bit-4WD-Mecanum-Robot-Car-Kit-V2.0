## 3.Makecode Extension Libraries

Nous avons créé une bibliothèque d'extension Makecode pour cette voiture robot Mecanum V2.0.

Ajoutez une bibliothèque d'extension pour la voiture robot Mecanum V2.0.

Veuillez suivre les étapes suivantes pour ajouter les fichiers d'extension :

Ouvrez Makecode pour accéder à un projet → cliquez sur l'icône en forme d'engrenage (pour les paramètres) en haut à droite → choisissez “**Extensions**”;

![makecode20](./media/Makecode_139fb536.png)

Ou cliquez sur “**Extensions**”, comme indiqué ci-dessous :

![makecode21](./media/Makecode_905cacbd.png)

Saisissez le lien :

```
https://github.com/keyestudio2019/mecanum_robot_v2
```

Appuyez sur le résultat de la recherche “**MecanumRobotV2**” pour le télécharger et l'installer. Ce processus peut prendre quelques secondes.

![makecode22](./media/Makecode_605b9b18.png)

Après l'installation, vous pouvez trouver les fichiers d'extension **Mecanum RobotV2** et **IrRemote** sur le côté gauche.

Le fichier d'extension Neopixel est également installé.

![makecode23](./media/Makecode_0c07886b.png)
