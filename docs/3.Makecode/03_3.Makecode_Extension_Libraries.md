## 3.Makecode Extension Libraries

Wir haben eine Makecode-Erweiterungsbibliothek für dieses Mecanum-Roboterauto V2.0 erstellt.

Fügen Sie die Erweiterungsbibliothek des Mecanum-Roboterautos V2.0 hinzu.

Bitte befolgen Sie die folgenden Schritte, um die Erweiterungsdateien hinzuzufügen:

Öffnen Sie Makecode und gehen Sie in ein Projekt → klicken Sie auf das zahnradförmige Symbol (für Einstellungen) oben rechts → wählen Sie “**Extensions**”;

![makecode20](./media/Makecode_139fb536.png)

Oder klicken Sie auf “**Extensions**”, wie unten gezeigt:

![makecode21](./media/Makecode_905cacbd.png)

Geben Sie den Link ein:

```
https://github.com/keyestudio2019/mecanum_robot_v2
```

Klicken Sie auf das Suchergebnis “**MecanumRobotV2**”, um es herunterzuladen und zu installieren. Dieser Vorgang kann einige Sekunden dauern.

![makecode22](./media/Makecode_605b9b18.png)

Nach der Installation finden Sie die Erweiterungsdateien **Mecanum RobotV2** und **IrRemote** auf der linken Seite.

Die Erweiterungsdatei Neopixel ist ebenfalls installiert.

![makecode23](./media/Makecode_0c07886b.png)
