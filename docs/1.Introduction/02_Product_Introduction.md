## Introducción del producto

![](./media/Introduction_3c983f62.jpg)

¿Te has preguntado aprender programación o tener tu propio robot programable? Hoy en día, la programación se ha dirigido a grupos de edad más bajos, y será una tendencia para todos gracias a la difusión de plataformas de programación gráfica simples, desde micro:bit hasta Arduino y Raspberry Pi. Quizá no hayas oído hablar de ellos antes. Sin embargo, con la ayuda de este producto y el tutorial, puedes instalar fácilmente un coche programable multifuncional y experimentar la diversión de ser un maker.

Micro:bit es un microcontrolador altamente integrado con funciones potentes y tamaño reducido. Es muy adecuado para aplicarse en la educación STEAM por sus capacidades para crear robots, dispositivos wearables y juegos electrónicos interactivos mediante la combinación de programación por código y programación gráfica.

Este Keyestudio 4WD Mecanum Robot Car V2.0 es un coche inteligente DIY dedicado a micro:bit. El coche inteligente consta de un chasis con funciones ampliadas, una placa base PCB con controlador de motor y sensores integrados, 4 motores DC reductores, ruedas Mecanum, varios módulos y sensores, así como placas acrílicas. Por lo tanto, puedes ensamblar fácilmente tú mismo un genial coche inteligente 4WD con ruedas Mecanum y luego usar la plataforma de programación gráfica en línea de Microsoft, Make Code, para programar la placa de control micro:bit y controlar el coche. En el proceso, no solo puedes experimentar la diversión de crear, sino también mejorar la habilidad manual y aprender habilidades de programación.

MakeCode for micro:bit es el entorno de programación gráfica más utilizado en la web oficial de micro:bit. Se basa en el entorno de programación gráfica desarrollado por el proyecto de código abierto MakeCode de Microsoft. Esta programación gráfica también puede convertirse a lenguajes de código, Python y JavaScript, lo que hace que aprender a programar sea más accesible. Al mismo tiempo, la programación con MakeCode puede simularse o programarse para componentes electrónicos reales.

Para su conveniencia, se ha proporcionado el código fuente en cada proyecto, así como los pasos de programación del código y la explicación detallada del mismo. Esperamos que esto le ayude a comprenderlos mejor.
